# Cantina Express

"Crea una aplicación web y móvil tipo PWA moderna y altamente vistosa para la 'Cantina Universitaria'. Debe estar diseñada para que los alumnos hagan sus pedidos de comida sin filas y el personal de la cantina gestione los pedidos y el stock en tiempo real.

Estilo Visual y Diseño (UI/UX):

Estética: Limpia, juvenil, rápida y muy apetitosa. Usa tonos cálidos (naranja suave, verde fresco y detalles en blanco/gris claro).

Ilustraciones temáticas: Incorpora ilustraciones o tarjetas con fondos visuales representativos de comida de cantina (croissants, empanadas, sándwiches, minutas, jugos y bombones).

Diseño Adaptable (Responsive): La app debe lucir perfecta tanto en celulares como en tablets y pantallas de PC.

Funcionalidades requeridas para la vista de Alumno:

Encabezado: Saludo personalizado al alumno, barra de búsqueda y carrito de compras visible.

Categorías Ilustradas: Botones con iconos para 'Desayunos/Panadería', 'Minutas/Almuerzos', 'Bebidas' y 'Postres'.

Catálogo de Productos con Indicadores de Stock:

Cada producto debe mostrar foto/ilustración, nombre, descripción y precio.

Etiquetas de disponibilidad dinámicas:

Verde: "Disponible (Stock: 12)"

Naranja: "¡Últimas unidades! (Stock: 3)"

Rojo: "Agotado" (Deshabilita el botón de agregar al carrito).

Flujo de Pago y Finalización:

Selección de método de pago: 'Efectivo en Caja' o 'Tarjeta/Digital'.

Campo para nota personalizada (Ej: 'Sin mayonesa' o 'Retiro a las 10:15 hs').

Generación de un boleto digital/código con el número de pedido y estado (Ej: 'En preparación').

Funcionalidades para el Panel de Cantina (Toggle/Vista de Administrador):

Vista en tiempo real de pedidos entrantes clasificados por estado: 'Pendiente', 'En preparación' y 'Listo para retirar'.

Control de inventario donde el personal pueda editar el número de stock de cada producto o marcarlo como 'Agotado' con un clic.

Genera la interfaz completa con datos de prueba atractivos para simular el funcionamiento real."
